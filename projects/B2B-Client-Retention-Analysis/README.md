# B2B Client Retention Analysis

How I measured and improved client retention at Leena AI, a B2B SaaS company, during my time in marketing analytics and revenue operations (2022 to 2023).

## The problem

Account and lead data had gaps and errors. That made pipeline and renewal reporting hard to trust, so it was hard to see which clients were at risk.

## What I did

- Tightened data quality checks in the CRM
- Researched 1,000+ accounts to fill gaps in firmographic data
- Reworked how leads were managed and routed

## Results

| Metric | Change |
|---|---|
| Client retention | 76% to 88% |
| Data accuracy | +25% |
| CRM errors | -15% |
| Conversion efficiency | +20% |

## What's in this repo

- `cohort_retention.sql`: a template for tracking retention by sign-up cohort, written against a generic `accounts` and `contracts` schema

Company data is confidential and is not included. The query is a reusable template, not production code.
