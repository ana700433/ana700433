# Portfolio Website

Source for [anamikakumari.com](https://anamikakumari.com), my marketing analytics portfolio.

- Single-page site in plain HTML, CSS and JavaScript, no build step
- Scroll and hover animations, light and dark themes
- Respects reduced-motion settings

## Run it locally

Open `index.html` in a browser.

## Deploy

Upload `index.html` and the `images/` folder to the web root (`public_html` on Hostinger).
