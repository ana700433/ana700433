# Compliance Reporting Automation

Dashboards and an automated notification flow I built for compliance reporting across 100+ residential properties at MAC Properties (2024 to 2026).

## The problem

Compliance status was tracked by hand across many properties. Audits took long, and lease deadlines were easy to miss.

## What I did

- Built real-time Power BI dashboards showing compliance status by property
- Built a Power Automate flow that sends lease notifications ahead of key dates
- Worked within Yardi Voyager compliance workflows

## Results

- Audit efficiency improved by 20%

## How the notification flow works

1. A scheduled trigger runs every morning
2. The flow reads upcoming lease dates from a shared list
3. It keeps only the records that fall inside the notice window
4. A templated email goes to the right team, and the record is marked as notified

## Tools

Power BI · Power Automate · SQL · Excel
