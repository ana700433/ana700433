# Chicago Rental Market Dashboard

A Tableau dashboard comparing Chicago neighborhoods by rent level and price band, built while I worked in marketing operations at MAC Properties.

## The question

Where does a listing sit against the wider Chicago market, and which neighborhoods compete on price?

## What I built

- A clean, Tableau-ready dataset of Chicago rental listings
- A dashboard to compare neighborhoods, unit types and price bands
- Filters so leasing and marketing teams could check one area at a time
