01MAC Properties · macapartments.com

Where apartment hunters drop off

GA4 funnel analysis in Python

Problem

Site traffic was healthy, but nobody could say where visitors gave up before contacting the leasing team.

What I did

Pulled GA4 event data into Python and built a step-by-step funnel from search to property page to call-to-action.

Result

Found a 78.1% drop between search and property pages, and 98.8% of property-page visitors never clicked the CTA. Two clear places to fix first.
